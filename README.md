# Ekospec — efektywność energetyczna i instalacje

Niższe rachunki za energię i instalacje, które wreszcie działają.
Audyty energetyczne, planowanie modernizacji, diagnoza trudnych problemów
z ogrzewaniem, wentylacją i chłodzeniem, automatyka budynkowa.

🌐 **[ekospec.pro](https://ekospec.pro/?z=github)** · 📞 +48 573 018 657 · Nowy Targ, działamy w całej Polsce

To repozytorium zawiera kod strony ekospec.pro (statyczny HTML/CSS/JS, GitHub Pages).
Szablony podstron są w `_strony/` i `_partials/`, strona budowana przez `python _build.py`.
